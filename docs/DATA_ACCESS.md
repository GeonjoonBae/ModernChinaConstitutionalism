# 데이터 접근과 공개 범위

## 공개하는 자료

- 연구자가 작성한 토큰 병합·불용어·이체자 규칙
- 문맥 및 토큰 필터의 규칙과 식별자
- 일별·시기별 집계값
- 공기어 네트워크의 집계 edge
- 네트워크 유사도와 pair-conditioned keyness 결과
- 논문에 사용한 그림과 독립형 HTML 대시보드
- 분석 코드와 재현 문서

## 공개하지 않는 자료

- 상하이도서관 『申報』 DB에서 수집한 기사 원문
- 핵심어 중심 문맥 전체
- CKIP NLP JSONL
- 문맥의 토큰열을 그대로 복원할 수 있는 token-level parquet
- 원문을 포함하는 대형 context evidence 파일

상하이도서관 인증 이용 자료의 재배포 범위가 명확히 확인되지 않았으므로, 원문과 원문을 실질적으로 복원할 수 있는 중간 데이터는 공개 대상에서 제외한다.

## 식별 정보

정성적 인용 근거를 확인할 수 있도록 기사 날짜, 제목, `article_id`, `context_uid`는 제공한다. 실제 원문과 논문에 제시한 번역은 논문 본문 및 적법한 데이터베이스 접근 경로를 통해 확인해야 한다.

## 라이선스

현재 저장소의 코드와 집계 데이터에 적용할 별도 공개 라이선스는 확정되지 않았다. 라이선스 파일이 추가되기 전까지 일반적인 저작권 원칙이 적용된다. 외부 연구자가 재사용하거나 재배포할 경우에는 저장소 저자에게 이용 범위를 확인해야 한다.
